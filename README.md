# Xiaoxiao — a writer's notebook

A small, zero-build static site: stories, essays and verse by **Xiaoxiao**, each piece
with its own cover and illustrations. Bilingual — English and 中文.

- No frameworks, no build step: plain HTML + one stylesheet + one small lightbox script.
- Every work lives in its own folder: `works/<slug>/` with `index.html` (English),
  `zh.html` (中文, where translated) and its images.
- Design language: a theatre programme — Bodoni Moda & Newsreader (思源宋体 for Chinese),
  moonlit paper, oxblood velvet, dim gold.

## Run locally

Open `index.html` directly (all links are relative), or:

```bash
python -m http.server 8734
```

then visit http://localhost:8734.
